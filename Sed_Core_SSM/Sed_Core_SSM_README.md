# Southern California Bight (SCB) Sediment Core Correlation State-Space Model (SSM)

This repository contains an R and Stan workflow for comparing fish scale deposition rates (SDRs) from four sediment cores and assessing their correlation through time. The cores were taken from the Santa Monica and Santa Barbara Basins. The model estimates a latent ln(SDR) trajectory for each core on a common time grid and the correlation among cores.

- **`R/`**: the three analysis scripts (described below).
- **`Data/`**: input Excel files.
  - The four core files (`Santa_Monica_Basin.xlsx`, `SH2015_...`, `Baumgartner1992_..._214`, `Baumgartner1992_..._224`) hold the SDR records used to fit the model. See the top rows of each file for metadata.
  - The three covariate files (speleothem-based SST, Mo, and *Rhizosolenia* spp. diatom data) and the CalCOFI temperature file are used only for supplementary figures.
- **`Stan/`**: the Stan model.
- **`Stan_run/`**: all outputs. Everything in this folder is regenerated by running the scripts.

All file paths are built with the [`here`](https://here.r-lib.org/) package, which finds the project root from the `.Rproj` file. You do not need to set a working directory or edit any paths.

## Dependencies
- R
- [CmdStan](https://mc-stan.org/cmdstanr/) (via cmdstanr; rstan is used as a fallback if cmdstanr is unavailable)
- Packages: here, readxl, dplyr, tidyr, tibble, posterior, ggplot2, patchwork, scales, cmdstanr
```r
install.packages(c("here", "readxl", "dplyr", "tidyr", "tibble", "posterior", "ggplot2", "patchwork", "scales"))

install.packages("cmdstanr", repos = c("https://stan-dev.r-universe.dev", getOption("repos")))

```
## Recommended workflow
Run the scripts in this order:
1. Verify that the Excel files are in `Data/` and `Sed_Core_SSM_model.stan` is in `Stan/`. Inspect the header rows as needed.
2. Open the `.Rproj` file in RStudio. This sets the project root for `here()`. If not using RStudio, run `here::set_here()` once in the project folder.
3. Run `R/Sed_Core_SSM_fit.R`. This loads the data, builds the Stan data list, compiles and samples the model, and saves fit objects and diagnostics to `Stan_run/`.
4. Run `R/Sed_Core_SSM_plot.R`. This loads the saved fit and produces the two main figures in `Stan_run/Figures/`.
5. Run `R/Sed_Core_SSM_supplementary_plots.R`. This loads the saved fit and the covariate and CalCOFI temperature data, and produces the four supplementary figures in `Stan_run/Figures/Supplementary figures/`.

## File details
### `Stan/Sed_Core_SSM_model.stan`
The Stan source code defining the model and its associated likelihoods, detection limits, and priors.

### `R/Sed_Core_SSM_fit.R`
The data pre-processing and execution script that contains code to:
- load the four cores' SDR records from Excel
- build a common time grid (385-1795 AD in 10-year steps) and assign each observation to a grid bin
- treat zero SDR values (detection limit of ln(minimum non-zero SDR / 2))
- construct the Stan data list and set of core pairs
- configure the sampler (4 chains, 2000 warmup and 2000 sampling iterations, `adapt_delta` = 0.999, `max_treedepth` = 12, LKJ prior with eta = 1)
- compile and sample `Sed_Core_SSM_model.stan` via cmdstanr (falls back to rstan if cmdstanr is unavailable)
- print sampler diagnostics and a summary of the main parameters
- save the fit object, draws, and the processed data objects to `Stan_run/`
- when run with cmdstanr, write `Posterior_summary.csv` (mean, median, SD, 5% and 95% quantiles, and convergence measures for the main parameters)

### `R/Sed_Core_SSM_plot.R`
Post-processing script that reads the posterior draws and generates the two main figures in `Stan_run/Figures/`:
- **`fig_SDR_trajectories.png`**: Latent ln(SDR) trajectories per core (posterior median with 50% and 90% credible-interval ribbons).
- **`fig_typical_and_pairs_correlation.png`**:
  - **(A)** Posterior histogram of the median cross-core correlation (`median_r`, computed as tanh of `z_mean`), shaded by 50%, 70%, and 90% credible intervals, with the posterior median and 90% interval marked.
  - **(B)** A pairwise correlation matrix showing the posterior median and 90% credible interval for each core pair.

### `R/Sed_Core_SSM_supplementary_plots.R`
Reads the saved fit plus the covariate and CalCOFI temperature data and generates four figures in `Stan_run/Figures/Supplementary figures/`:
- **`Supplementary_Fig_1.png`**: Posterior distributions of the correlation for each core pair, with the proportion of the posterior above and below zero and the posterior median.
- **`Supplementary_Fig_2.png`**: Stacked panels over 950-1450 AD (z-scored) comparing the latent SDR trajectories (50% CrI) with SST anomaly, Mo (Mo<sub>EF</sub>, oxygen proxy), and *Rhizosolenia* spp. abundance (upwelling indicator). 
- **`Supplementary_Fig_3.png`**: Comparison of CalCOFI mean temperature (0-100 m) between the Santa Monica Basin (line 86.7, station 35.0) and Santa Barbara Basin (line 81.8, station 46.9) stations, 1984-2021.
- **`Supplementary_Fig_4.png`**: Scalar forest plot of the posterior median and 90% credible interval for the parameters μ, ρ, σ<sub>proc</sub>, and τ<sub>obs</sub>.
